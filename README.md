# B208 Advanced Algorithms - Emergency Routing Project

This repository contains my final project for the B208 Advanced Algorithms module. The goal of this project is to enhance the efficiency of emergency services in Germany by building a city map graph and applying pathfinding algorithms to route ambulances to the nearest hospital.

For this implementation, I chose Nuremberg as my mid-sized city. I built the graph using OSMnx and queried Google Maps for the nearest hospital. I then implemented and benchmarked two different algorithms (Breadth-First Search and Dijkstra) to compare their efficiency and effectiveness.

## Project Structure
- `pathfinder.py`: The main script containing the graph generation, algorithm logic, and benchmarking tests.
- `requirements.txt`: The required Python packages to run the project.
- `.env` (not included): You will need to create this file to hold your Google Maps API key.
- `scenario_*_route.png`: Output images generated by the script showing the final calculated routes.

## How to Run

1. **Install Dependencies**
   Make sure you have Python installed, then install the required libraries:
   ```bash
   pip install -r requirements.txt
   ```

2. **Add API Key**
   Create a `.env` file in the same directory as the script and add your Google Maps API key like this:
   ```
   GOOGLE_MAPS_API_KEY=your_api_key_here
   ```

3. **Execute the Script**
   Run the main python file. It will download the city graph, locate the hospital, run 5 random routing scenarios, and print the performance benchmarks to the console.
   ```bash
   python pathfinder.py
   ```

## Customization

### Changing the Target City
If you want to run the pathfinding algorithms on a different city, you only need to change a single line of code! 

Open `pathfinder.py` and modify the `place` variable near the top of the file:
```python
place = "Nuremberg, Germany" # Change this to any city, e.g. "Munich, Germany"
```
The script will automatically reach out to OSMnx to download the new city's road network, and dynamically ask Google Maps to find a hospital inside that new boundary.
